# ❄️ Stock Snowball

## **[👉 jinhoops.github.io/stock-snowball](https://jinhoops.github.io/stock-snowball/)**

매일·매주·매월 조금씩 넣은 돈이 복리로 얼마나 불어나는지 눈덩이처럼 보여주는 적립식 투자 시뮬레이터입니다. 설치나 가입 없이 브라우저에서 바로 쓸 수 있습니다.

## 무엇을 할 수 있나요

| 모드 | 하는 일 |
|---|---|
| ❄️ **스노우볼** | 초기 자금, 납입액, 기간, 기대 수익률을 넣으면 미래 자산이 어떻게 자라는지 보여줍니다. 수익률은 직접 정하거나 QQQ·SPY·KOSPI 200·금 같은 자산의 과거 성장률을 쓸 수 있고, 결과가 흔들릴 수 있는 범위와 원금 손실 가능성도 함께 보여줍니다. |
| 📈 **백테스트** | "그때부터 꾸준히 샀다면?"을 실제 과거 시세로 계산합니다. 배당 재투자, 최대낙폭, 전고점 회복까지 걸린 시간도 함께 봅니다. |

그 밖에

- **레버리지 비교**: `QQQ · QLD · TQQQ`처럼 원상품과 2배·3배 상품을 같은 기간에 나란히 비교합니다.
- **폭락 구간 넣고 빼기**: 닷컴 버블, 글로벌 금융위기 같은 큰 폭락을 계산에 넣을지 하나씩 고를 수 있습니다.
- **돈의 가치 기준 바꾸기**: 그때 금액 그대로, 물가를 반영한 금액, 금으로 환산한 가치 중에서 고릅니다.
- **원화·달러 전환**, 수수료와 ISA 계좌 세금 추정.
- **시나리오 저장·비교**: 조건을 저장해 두고 나중에 불러오거나 여러 개를 겹쳐 봅니다. 저장한 내용은 내 기기에만 남습니다.
- **앱처럼 설치**: 홈 화면에 추가할 수 있고, 인터넷이 끊겨도 마지막으로 받은 데이터로 계산합니다.

## 지원 자산

`QQQ` `QLD` `TQQQ` `AMD` `AMDL` `TSLA` `TSLL` `SOXX` `SOXL` `SPY` `SCHD` `KOSPI 200` `KOSDAQ` `GOLD`

시세는 매일 자동으로 갱신됩니다. 새 데이터가 오면 화면에 「새로고침해 적용」이 뜨고, 보던 결과가 몰래 바뀌지는 않습니다.

## 알아두세요

- **투자 권유가 아닙니다.** 과거 수익률이 미래를 보장하지 않습니다.
- **2배·3배는 하루 목표입니다.** 레버리지 상품의 장기 수익은 기초자산의 단순 2배·3배와 크게 다를 수 있습니다.
- **스노우볼의 범위(하위 10%~상위 10%)는 추정입니다.** 과거 흐름을 다시 섞어 만든 가능성이며, 결과가 그 안에 든다는 보장은 없습니다.
- **폭락 구간을 빼면 결과가 낙관적이 됩니다.** 같은 폭락이 다시 오면 결과보다 나빠집니다.
- **세금과 비용은 단순화했습니다.** 백테스트는 매수 수수료와 ISA 만기 세금만 반영하고, 매도 수수료·배당세·양도소득세는 계산하지 않습니다.
- **금 기준은 대략적인 비교입니다.** 금 선물(`GC=F`) 가격으로 환산하며, 실물 금 거래 가격이나 비용은 아닙니다.

### 기술 스택

React + Vite PWA, TypeScript, Tailwind, visx(차트), anime.js·framer-motion(모션), RxDB(시나리오 저장), `decimal.js`(금융 계산). 시세는 Python(`uv`) 스크립트가 GitHub Actions에서 수집해 Supabase Storage에 게시합니다.

### 로컬 실행과 검사

```bash
npm install
npm run dev            # 주소 경로는 /stock-snowball/

npm test               # 단위 테스트
npm run test:e2e       # Playwright E2E
npm run design:check   # 디자인 토큰 검사
npm run build
```

시세 도구는 Python 3.13을 씁니다.

```bash
uv python install 3.13
uv sync --locked
npm run data:check     # 외부 통신 없이 동봉 CSV·매니페스트 검증
npm run data:refresh   # 외부 시세를 수동 조회해 갱신 (보정·분할 같은 예외 작업용)
```

### 계산 기준

- 스노우볼의 수익률·물가·환율 변화율은 연 유효율이고 1년을 365일로 계산합니다. 시작점에 초기 원금만 넣고, 이후 평일·월요일·매월 1일 중 고른 주기로 납입합니다. 시장 공휴일은 반영하지 않습니다. 가치 분할 매수는 월간 목표로 계산합니다.
- 백테스트는 실제 데이터 날짜를 쓰고 첫 날짜에 초기 원금과 첫 적립금을 함께 넣습니다. 배당락일 이전 보유 수량에만 배당을 주고, 재투자하지 않은 배당은 현금으로 둡니다.
- 상품 CAGR과 포트폴리오 IRR을 구분하며, 날짜 기반 연환산은 365.25일입니다. 변동성은 표본 일 표준편차의 `sqrt(252)` 연환산입니다. 연환산할 수 없는 IRR은 0%로 대신 표시하지 않습니다.
- 스노우볼의 참조 자산 수익률은 배당 포함 전체 이력 CAGR이고, 범위는 과거 수익률을 1년 블록으로 재표집해 만듭니다. QLD·TQQQ의 상장 전 구간은 QQQ 일간 수익률 ×2·×3에서 하루 비용을 빼 재구성합니다.
- 스노우볼은 매수·매도 수수료와 세금 추정치를 포함합니다. 일반계좌 세금은 양의 전체 이익에 배당세율을 적용하는 단순 모델이고, ISA 기본값은 공제 200만원·초과분 9.9%입니다.
- 백테스트 비교는 합성 이력 없이 실제 거래 데이터만 쓰므로, 고른 상품이 모두 있는 공통 기간으로 제한됩니다. 상품 성과 지표는 세전이며, 펀드 보수와 추적 차이는 거래 가격에 이미 반영된 것으로 봅니다.
- 전고점 회복 시간은 상품 총수익 지수(배당 재투자, 적립금 제외)에서 최대낙폭을 만든 전고점부터 처음 그 값을 되찾은 날까지의 달력 일수입니다. 못 되찾았으면 `미회복`과 마지막 관측일까지의 경과일을 보여줍니다.
