# 2026-09-28 시장 데이터 갱신 및 국내 지수 대조

`npm run data:check`는 기존 17개 시리즈를 통과했다. 첫 `npm run data:refresh`는 다음 오류로 원자적 설치 전에 중단됐다.

> Market data error: kospi.csv has an unreviewed daily data gap from 2026-09-08 to 2026-09-28 (20 calendar days)

기존 CSV는 이때 바뀌지 않았다. 같은 기간을 직접 조회한 Yahoo Finance `^KS200` 일별 응답은 2026-09-28 한 행뿐이었다. `^KQ11`의 현재 응답에는 기존 CSV에서 누락된 2026-08-28, 09-03과 기존 값과 다른 09-04, 09-08 종가가 있었다. 날짜는 모두 `exchange_calendars` 4.13.2의 XKRX 거래일이다. 따라서 단순 휴장일이나 날짜 변환 문제가 아니라 제공자 응답의 누락과 이전에 수집된 값의 불일치로 판단했다. 이전 수집 시점의 Yahoo 원본 응답은 보관되지 않아, 값이 언제 바뀌었는지는 확정할 수 없다.

## 최종 검증

오프라인 데이터 검사, Python 테스트 47개, 프런트엔드 테스트 296개, 프로덕션 빌드를 통과했다. 독립 리뷰에서도 17개 CSV의 기존 날짜 삭제가 없고, 과거 값 변경이 위에 명시한 두 지수의 09-04·09-08 종가뿐임을 확인했다. 매니페스트의 시작일·종료일·행 수는 각 CSV와 일치한다. 제공자 수정 시점은 확인할 수 없으므로 출처 사유에도 과거 저장값과 검토값의 차이만 기록했다.

모바일 흐름과 회복 기간 기능의 전체 E2E 42개도 통과했으며 [화면 점검 보고서](design-qa/2026-09-28-backtest-flow.md)에 캡처를 남겼다. 위 검증은 커밋·푸시·배포 전에 수행했다.
