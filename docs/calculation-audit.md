# 계산 신뢰도 점검

점검일: **2026-09-10**

미래 시뮬레이션과 과거 백테스트의 계산, 입력 통화, 저장·비교, 차트 전달 경로를 점검하고 재현한 오류를 수정했다. 기존 두 엔진과 정적 시세 데이터를 유지했으며, 의존성 추가나 CSV 갱신은 하지 않았다. 아래의 계산 검증은 시세 원본의 정확성이나 미래 수익률을 보증하는 검증과 구분한다.

## 수정한 오류

| 영역 | 확인한 문제와 수정 |
|---|---|
| 연 수익률·물가·환율 | 연 수익률을 `r / 365`로 나누어 복리 계산하던 방식을 연 유효율에 맞게 수정했다. 수수료·세금 없는 100만원의 연 10% 결과는 종전 1,105,156원에서 1,100,000원으로 바뀐다. 같은 기준으로 물가와 연 환율 변화율도 계산한다. |
| 납입 날짜·기간 | 미래 시뮬레이션에서 당일 납입을 다음 날 기록하던 순서를 수정했다. 월 1일·종료일 납입, 소수 연수의 마지막 날짜, UTC와 지역 날짜 혼용을 검증했다. 백테스트는 요청한 종료일을 엔진 안에서 조용히 단축하지 않는다. |
| 금액·환율 단위 | 계산 도중 정수로 반올림하여 소액 잔고가 사라지던 문제를 수정했다. 환율 변동으로 과거 납입 원금까지 재평가하지 않고 납입 시점의 환율로 원가를 누적한다. 매수·매도 수수료도 같은 출력 통화로 합산한다. |
| 배당 | 배당락일 종가에 새로 산 주식에는 해당 배당을 지급하지 않는다. 미재투자 배당은 현금으로 남긴다. 배당 포함 상품 수익률, 납입과 분리한 CAGR·낙폭·변동성을 정합화했다. 연 배당 추정은 마지막 날 배당의 12배 대신 종료 보유 수량과 직전 12개월의 주당 배당 합계를 사용한다. |
| 급락·잔고 | 잔고가 납입 원금의 1% 미만이라는 이유로 양수 가격의 보유 주식을 강제 소멸시키던 조건을 제거했다. |
| 가치 분할 매수 | 저장된 월 목표 또는 기본 납입액을 월간 목표 증가액으로 사용한다. 달력상 월 1일에 부족액을 매수하며 매수 수수료를 포함해 필요한 납입액을 계산한다. 기존 `generateSeries`도 일 납입액을 월 납입액으로 잘못 확대하지 않는다. |
| IRR | 납입 시점을 무시한 최종 가치/총 납입금 연환산 대신 실제 현금흐름 날짜로 계산한다. 차트의 표시 간격이 IRR에 영향을 주지 않는다. 로그 수익률 공간과 크기를 조정한 NPV로 50년 계산의 오버플로를 방지하고, 기존 상·하한 밖의 단기 극단 수익률도 표현 가능한 범위에서 찾는다. 보유기간 없이 마지막 날 납입·수수료만 발생한 경우 등 연환산 불가 결과는 `null`로 구분한다. |
| 저장·통화 전환 | USD 표시의 ISA 공제 한도를 환산하고 저장된 금액·월 목표를 현재 통화로 변환한다. 저장된 세율·수수료·환율 변화·배당 재투자·참조 수익률이 비교와 불러오기에서 달라지던 문제를 수정했다. 불러오기→통화 전환→재접속→다시 저장의 금액 일치도 검증했다. |
| 차트 | 배열 순번 대신 실제 경과 날짜로 비교선을 정렬한다. 각 시나리오의 표시 간격에 맞게 hover 값을 찾고, 기간 밖 시나리오의 오래된 값을 재사용하거나 없는 점을 참조하지 않는다. |
| 설정·표시 | 백테스트 계산에 영향을 주지 않는 기대 수익률·적립 전략 선택을 숨겼다. 가치 분할 매수는 본문과 공유 이미지 모두 실제 월간 목표액을 표시하며, 저장한 참조 수익률과 계산 불가 IRR 표시를 실제 계산 결과와 맞췄다. 원화 손실 금액이 빈칸으로 나오거나 1만원 미만 잔고가 0원으로 표시되던 문제도 수정했다. |
| 데이터 갱신 경계 | 증분 갱신의 새 행에서 주식 분할을 발견하면 중단하고 전체 이력 재생성을 요구한다. 분할 전후 서로 다른 조정 기준의 이력이 섞이는 것을 막는 검사이며 자동 갱신 기능은 아니다. |

배당 권리의 날짜 기준은 [SEC Investor.gov의 배당락일 설명](https://www.investor.gov/introduction-investing/investing-basics/glossary/ex-dividend-dates-when-are-you-entitled-stock-and?mod=article_inline)을, 현금흐름을 반영한 수익률 구분은 [CFA Institute의 수익률 설명](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/rates-and-returns)과 [성과 보고 설명](https://blogs.cfainstitute.org/insideinvesting/2013/10/09/performance-reporting-winning-the-scoreless-game/)을 참고했다. 분할 조정 이력의 재조회 필요성은 [yfinance 유지관리자 설명](https://github.com/ranaroussi/yfinance/discussions/1682)과 맞춰 점검했다.

## 검증 결과

기존 테스트가 구현의 잘못된 수식을 그대로 기대값으로 삼은 경우가 있어, 독립 수식과 손으로 계산할 수 있는 사례를 추가했다.

| 검증 | 결과 |
|---|---|
| 변경 전 기준 | 30개 테스트 파일, 215개 테스트 통과 |
| 독립 미래 시뮬레이션 검산 | 18개 사례: 납입 일정, 음수 수익률, 환율, 수수료·세금, 물가를 별도 수식과 비교 |
| 독립 백테스트 검산 | 14개 자산 전체에서 84개 사례, 배당 재투자·현금 보유 모두 비교 |
| 과거 참조 수익률 검산 | 14개 자산의 배당 포함 252개 일 수익률 구간 중앙값 비교 |
| 독립 검산의 수치 차이 | 검산에서 관측한 최대 차이 약 `1e-13` 수준. 화면 표시 반올림과 원본 시세 오차를 뜻하지 않음 |
| 날짜·표시 회귀 검사 | 서울·뉴욕 시간대, 월말·연 경계, 소액·빈 투자, 서로 다른 차트 간격, 저장·통화 전환 사례 확인 |
| 최종 전체 프런트엔드 테스트 | `npm test`: 35개 파일, **282개 테스트 통과** |
| 최종 데이터 검사·Python 테스트 | `npm run data:check` 통과. `uv run python -m unittest tests/test_market_data.py`: **45개 테스트 통과** |
| 최종 프로덕션 빌드 | `npm run build` 통과: TypeScript, Vite, PWA 생성 완료 |

독립 검산은 엔진 구현과 별도로 수행하고 백테스트·차트의 회귀 검사와 함께 검토했다. 최종 프런트엔드 검사와 빌드는 공유 이미지 표시 수정까지 포함한다. 테스트의 기존 jsdom `scrollTo` 안내와 빌드의 큰 청크 경고는 남아 있으며 검사 실패는 없었다. 연결 가능한 브라우저가 없어 실제 화면의 시각 검증은 수행하지 못했고, UI 수치·동작은 컴포넌트와 통합 테스트로 확인했다.

## 유지하는 계산 가정

| 항목 | 미래 시뮬레이션 | 과거 백테스트 |
|---|---|---|
| 시간 기준 | 1년=365일. 소수 연수는 가장 가까운 일수로 반올림 | 실제 데이터 날짜 간격. CAGR·IRR 연환산은 365.25일 |
| 최초 납입 | 시작점에는 초기 원금만 반영 | 첫 데이터 날짜에 초기 원금과 첫 적립금 반영 |
| 추가 납입 | 이후 평일마다, 월요일마다 또는 매월 1일. 종료일 포함. 시장 공휴일은 모델링하지 않음 | 존재하는 데이터 날짜 기준. 일 납입은 평일 행, 주 납입은 직전 납입 후 7일 이상인 첫 행, 월 납입은 새 달의 첫 행 |
| 성장·배당 | 연 유효 수익률로 매일 성장. 증액은 365일 경과마다 적용 | 종가와 별도 배당으로 보유 수량·현금을 계산. 배당 재투자는 배당락일 종가에서 즉시 실행하는 단순화 |
| 매수 비용 | 초기·추가 매수 수수료 | 초기·추가 납입의 매수 수수료. 배당 재투자에는 별도 수수료 없음 |
| 종료 비용·세금 | 매도 수수료와 세금 추정치 반영. 일반계좌는 양의 전체 이익에 배당세율을 적용하는 단순 모델 | ISA 종료 세금 추정만 반영. 매도 수수료·배당세·일반계좌 세금은 계산하지 않음 |
| 성과 구분 | 포트폴리오 IRR은 실제 납입 날짜와 종료 세후 가치를 사용 | 포트폴리오 IRR과 납입을 배제한 상품 CAGR·낙폭·변동성을 구분 |

- ISA 기본값은 공제 한도 200만원, 초과 이익 세율 9.9%다. 저장된 사용자 설정은 유지한다. 이는 계좌 자격·만기·자산별 세법을 모두 재현하는 세금 계산기가 아닌 추정 모델이다. [KB증권 ISA 안내](https://www.kbsec.com/go.able?linkcd=s050801010000), [삼성증권 ISA 안내](https://www.samsungpop.com/mbw/finance/isa/guide.pop)
- 역사적 참조 연 수익률은 **배당을 포함한 252개 일 수익률**의 이동 구간 중앙값이다. 252개 가격 관측값과 구분한다. 변동성은 일 수익률의 표본 표준편차에 `sqrt(252)`를 곱한다. 실제 기간의 CAGR과 동일한 지표는 아니다.
- 낙관·비관선은 가정한 변동성과 시간의 제곱근으로 만든 예시 범위다. 검증된 90% 신뢰구간이나 미래 발생 확률을 의미하지 않는다. 가치 분할 매수도 평균 경로에서 계산한 같은 납입액을 세 경로에 적용한다.
- 소수 주식 매매와 종가 체결을 가정한다. 호가·슬리피지·지급일 지연 등을 재현하지 않는다. 펀드 보수와 실제 추적 차이는 가격에 이미 반영된 것으로 보고 다시 차감하지 않는다.
- 금 기준은 `GC=F` 선물 가격을 이용한 상대 가치 비교이며 실물 금 거래비용을 포함하지 않는다.

## 미확정 사항과 작업 경계

국내 데이터의 거래일 달력 대조에서 **KOSPI 200의 2026-09-02·09-03·09-07**, **KOSDAQ의 2026-08-28·09-03**에 불일치가 남았다. 제공자 날짜 처리, 누락 또는 달력 기준 중 어느 것이 원인인지는 확정하지 않았다. 이 점검에서는 해당 CSV와 매니페스트를 수정·갱신하지 않았으며, 해당 구간의 시세가 완전히 검증되었다고 주장하지 않는다.
